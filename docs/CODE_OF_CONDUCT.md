# Community Code of Conduct

TeleBook maintainers and contributors are committed to providing a welcoming, constructive environment for everyone.

## Core Expectations

- Treat all participants with respect and professional courtesy.
- Focus on constructive technical critique and factual discussion.
- Refrain from harassment, discriminatory remarks, or personal attacks.

Violations can be reported to shoumik.bala@gmail.com and will be handled promptly.
