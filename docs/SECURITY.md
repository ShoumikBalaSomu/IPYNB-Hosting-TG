# Security Policy

## Reporting Vulnerabilities

If you identify a security defect or potential exploit in TeleBook, please report it directly to the repository maintainer rather than opening a public issue.

Email: shoumik.bala@gmail.com

Reports should include:
- Description of the vulnerability and affected component.
- Reproduction steps or proof-of-concept payload.
- Recommended remediation if available.

Reports will be acknowledged within 48 hours.
